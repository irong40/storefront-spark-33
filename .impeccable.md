# Design Context — imPRESSive Juice Bar

## Product
Cold-pressed juice bar e-commerce site. Customers browse, order online for pickup (Tue–Sat) or delivery (Mon–Fri), buy wellness shots and detox packages, manage subscriptions, redeem gift cards, and earn loyalty rewards.

## Target Audience
Health-conscious consumers in the Chesapeake/Hampton Roads VA area. Mix of:
- **Regulars** — know what they want, want to reorder fast
- **Browsers** — discovering new juices, reading ingredient lists
- **Gift buyers** — purchasing gift cards for health-focused friends/family

## Brand Personality
Fresh, vibrant, approachable. NOT clinical wellness. NOT luxury spa. Feels like a neighborhood spot that takes quality seriously — warm, colorful, a little bold. The name "imPRESSive" plays on cold-pressing; the brand leans into that energy.

## Color System
- `brand-berry` — main CTA, accent (deep burgundy-raspberry)
- `brand-olive` — secondary actions, admin (earthy green)
- `brand-terracotta` — warm support color
- `brand-mustard` — highlights, tags
- `brand-cream / brand-cream-dark` — backgrounds, surface tones
- `brand-brown` — primary text
- `brand-warm-gray` — secondary text

## Typography
- **Display**: Playfair Display — used for headings, section titles
- **Script accent**: Cormorant — used for taglines (e.g., "Pressed to perfection")
- **Body**: Libre Franklin — UI text, nav, buttons

## Current Tech
Vite + React 18 + TypeScript + Shadcn/ui + Tailwind CSS + Supabase + Square Payments + Vercel

## Design Direction
**Organic Vivid** — the interface should feel like walking into the store: bright produce colors against warm cream surfaces, photography-forward, tactile. Cards should feel like labels. The emotional tone is energetic but not anxious — confident health. Think: Erewhon website meets local neighborhood juice bar warmth.

## Anti-Pattern Watchlist (project-specific)
- Cards must NOT be identical in rhythm — vary badge position, highlight treatment per product
- No blue/purple color creep — the palette is warm (berry, olive, terracotta, mustard). No cyan.
- Images must dominate cards — products are beautiful, show them large
- Typography hierarchy must be visible at a glance — don't let Playfair Display get lost

## Key Pages
- `/` — Home (hero, featured products, values)
- `/products` — Full menu
- `/products/:slug` — Product detail
- `/checkout` — Square payment form
- `/account` — Loyalty tier, order history
- `/gift-cards` — Gift card purchase and balance check
- `/admin` — 13-tab dashboard (admin only)
