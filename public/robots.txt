# One group for every crawler, including search engines and AI crawlers
# (Googlebot, Bingbot, GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot,
# Claude-User, PerplexityBot, Google-Extended, Applebot-Extended).
#
# Under RFC 9309 a crawler obeys only the most specific group that names it
# and does not inherit the "*" rules. A named group would therefore need its
# own copy of every Disallow line, and any group that forgot one would open
# checkout and account pages to that bot. Keeping a single "*" group gives all
# of them the same rules. To block or allow one bot differently, add a group
# for it that repeats every Disallow below.

User-agent: *
Allow: /
Disallow: /admin
Disallow: /checkout
Disallow: /account
Disallow: /order-confirmation
Disallow: /auth
Disallow: /reset-password
Disallow: /rewards
Disallow: /gift-cards/balance

Sitemap: https://www.impressivejb.com/sitemap.xml
